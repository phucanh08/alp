# @anhlp/alp-runtime

Viewer-neutral orchestration and normalized native provider adapters.

Build: `npm run build --workspace=@anhlp/alp-runtime`. Test: `npm run test --workspace=@anhlp/alp-runtime`.

Public imports use the package root and its explicitly exported subpaths. See [architecture, provider extension, compatibility and release instructions](../../docs/modular-monorepo.md).
