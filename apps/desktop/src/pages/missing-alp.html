ALP is not installed

This app opens the ALP already installed on this Mac, and it found no alp command.

The alpPath setting names , which is not an executable file.

Install ALP from a terminal:

npm install -g @anhlp/alp@beta

Other ways to install: docs/alp/beta-install.md in the ALP repository.

Installed somewhere else? Put its absolute path in ~/Library/Application Support/ALP/settings.json as { "alpPath": "/path/to/alp" }.

Then choose File › Connect again (⇧⌘R).
